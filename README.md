# HTML, CSS and Bootstrap Course Projects

Welcome to my project repository for the **CSS and Bootstrap** course at AOLCC! This repository contains all the hands-on projects, website builds, and practical implementations completed throughout the course modules.

---

## 📚 Course Structure & Completed Projects

### Module 1: CSS Fundamentals & Development Tools
Focuses on essential developer environments, version control, and core CSS syntax.
- **Tools Covered:** Visual Studio Code, Git, GitHub Extension, Node.js, Integrated Terminal, and LiveShare.
- **Key Concepts:** Selectors, Specificity, Parent/Child Relationships, Relative/Absolute Paths, and CSS Syntax.

---

### Module 2: Project - Space Resort Website
A multi-page responsive web development project focused on advanced layout techniques and visual enhancements.
- **Key Features:**
  - CSS Keyframe Animations & Pseudo-classes (`:hover`, `:nth-child`).
  - Flexbox layouts, Custom Favicons, and Media Queries.
  - Web Accessibility compliance (ARIA attributes, Screen Reader support).
- **Projects Included:**
  - `SpaceStationWebS` (Space Resort Website)

---

### Module 3: Dynamic Login Forms & Debugging
Focuses on code quality, cross-browser styling, and CSS debugging.
- **Key Concepts:** HTML/CSS Validation, Font Sizing Units (`rem`, `em`, `vh`, `vw`), and DevTools Debugging.
- **Implementations:** Clean form layouts and interactive user input components.

---

### Module 4: Responsive Websites with Bootstrap
Building modern, mobile-first responsive web applications using the Bootstrap framework.
- **Key Features:**
  - Integration via CDN & Custom CSS variables.
  - Bootstrap Grid System, Responsive Containers, Components, and Footers.
- **Projects Included:**
  - `Academy-Cinemas-main3` (Academy Cinemas Landing Page)

---

### Module 5: FTP, Hosting & Personal Portfolio Website
Final deployment phase involving hosting setup and building a centralized portfolio.
- **Key Concepts:** Filezilla (FTP/SFTP), Formspree.io Integration, and Live Website Hosting using **GitHub Pages**.
- **Portfolio Features:** Modern single-page portfolio linking all previous course projects.
